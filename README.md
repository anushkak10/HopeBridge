HopeBridge

HopeBridge is an orphanage donation app that I want to build to make it easier for people to help orphanages in different ways.

Users will be able to view orphanage profiles and donate things like books, food, money, medical kits, or even sponsor the education of children.

There will also be a section where users can see the difference their donation has made by comparing the data before and after the donation. The main idea is to make the impact of donations more visible instead of just showing that a donation was made.

I also want to tie up with delivery services so that people who cannot directly visit an orphanage can still send donations from their homes.

Key Features
Transparency — Only verified orphanages will be allowed on the platform.
Data Comparison — Users can see the difference their donations have made.
Delivery Services — People can send physical donations from their homes.
Volunteering — Users will also have the option to volunteer and help in other ways.
Different ways to donate — Books, food, money, medical kits and education sponsorship.
NOTE

This app is a work in progress and is something I want to build while acquiring the skills needed to build it.

I don't know everything needed to build the complete project yet, so I will be learning and adding things along the way.
